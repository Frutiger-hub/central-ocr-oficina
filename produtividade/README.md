# Produtividade Oficina

Aplicação web estática que substitui o fluxo principal da planilha de produtividade da oficina.

## Recursos

- Dashboard operacional.
- Filtragem por técnico, período, base e texto.
- Bases MONTADOS, ENROLADOR, APROVADOS, ANALISADOS e ERROS APONTAMENTO.
- Inclusão, edição, exclusão e pesquisa.
- Recalculo de status de prazo em MONTADOS.
- Exportação CSV e backup JSON.
- Importação de PDF no navegador para lançamento em MONTADOS.
- Persistência local com localStorage.
- Layout responsivo.

## Dados

A versão pública não inclui os dados reais da oficina. Isso evita publicar clientes, técnicos e registros operacionais em um repositório público. Use a opção Backup / dados para restaurar um backup JSON da sua base.

## GitHub Pages

A aplicação fica na pasta produtividade/. Com GitHub Pages apontando para a branch main, ela pode ser acessada em /central-ocr-oficina/produtividade/.
